## 今回の操作改善

- 戦闘画面を100dvhに固定し、PCは左に盤面、右に同期レーダーと行動設定を配置。行動／装備・向きタブとポップアップで切り替え、画面全体のスクロールを不要にした。スマホは盤面を残して行動設定・レーダーのドロワーを開閉する。長い一覧・詳細はポップアップ内部でスクロールする。
- 駒の右クリック／スマホの500ms長押しで円形メニューを表示。MAIN/SUBから本人の所持トリガーを選び、扇形をクリックした時点でコマンドと盤面の扇へ即反映する。移動・待機・護衛・追跡・詳細も輪から選択。選択した駒のM/SハンドルをドラッグしてMAIN/SUBの向きを変更し、離すと選択コマンドに反映。開始選択時は既存の装備変更と同じ5tick待機を追加する。接触のダブルクリックでタグ編集を開く。
- 3Dは左右30度のボタン、北へのリセット、Shift＋背景ドラッグで回転。建物・駒・弾・扇・経路・選択判定を同じ投影で扱う。平面・レーダーは北固定。
- 戦闘盤面とレーダーは同じ公開tickを使用。リプレイにも同じフレームのレーダーを配置し、再生・停止・シーク・視点に同期。前ターンの記録は演習・オンラインとも実行完了後に公開し、新ターンの未来フレームへ飛べないようにした。失探接触は最終報告地点を維持する。
- 非表示パネルのサイズ0による負の拡大率・描画例外を防止。部隊ポップアップの高さを固定してダブルクリック中の位置移動を防ぎ、担当変更の選択欄を右側に統一した。

## 性能

Windows、Intel Core i7-13700F、16コア・24論理CPU、Node.js 22.17.1。WASMハッシュ初期化後、C2固定プランの1ターン・151保存フレームを測定。I=18体551ms、II=28体597ms、III=48体839ms。全段階で解決1秒目標を達成。測定は特定シナリオ・端末での結果であり、全装備組合せや他端末の上限保証ではない。

自動試験は合計156件（指定7検証の152件とPages用4件）。production依存の`npm audit --omit=dev`も脆弱性0件。スクリーンショットは`output/game-wide.png`、`game-narrow.png`、`replay-wide.png`へ保存。
