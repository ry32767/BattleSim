# 識別アイコン・自作ベクター駒と装備

公開版の識別アイコンは自作ベクターを標準とする。個人用環境で`VITE_USE_OFFICIAL_ICONS=true`を設定した場合だけ、`apps/web/src/officialIcons.ts`の明示対応表から[公式S17配布ページ](https://worldtrigger.info/article/quiz.php)の画像URLを参照する。56名の対応を画像一覧で確認した。三雲は01、香取は63、隠岐は45、樫尾は53。漆間・ヒュース・佐伯・里見・宇野・片桐・一条・桃園の8名は配布一覧に対応を確認できず、割当なし。training/supplemented IDは同一人物へ解決する。読込失敗時にも既存の自作駒が下に残る。画像データを配布物に同梱せず、外部通信が必要。S17の配布条件と個人用採用指示は区別する。

画像はCanvasを汚染しないDOMの識別バッジとして描き、身体の実寸・向き・装備は下記の自作ベクターで表す。公式画像を4方向スプライトと呼ばない。レーダーにはアイコンを置かず、未視認・失探の敵には対応表を参照しない。

戦闘・リプレイのMAIN/SUB扇は生存味方と現在視認した敵に表示。通常扇は薄く、選択対象は太線・濃度・M/Sを強調する。敵の射程補正が非公開の場合は武器の基本射程を表示し、完全な判定範囲とは呼ばない。

公開イベントを最大5tick（0.5秒）保持し、発射の弾・軌跡、近接の斬撃弧、防御の盾、被害の火花、爆発の輪、装備アクション・準備・行動開始の発光とラベルを描く。新しい射撃記録は装備種と発射地点・照準を持つ。公開記録では見える射手のみ地点を開示する。旧記録など地点がない場合は公開方向の短い演出で示す。停止時は中間姿勢と記号を維持する。OSの`prefers-reduced-motion`では補間を止め、静止した軌跡・盾・ラベルを残す。モノクロ・動き軽減の画面ボタンは削除した。

`apps/web/src/pawns.ts` に64名の個別デザインと41装備の個別縮略形を保存する。全件が `evidenceStatus=original`、`sourceIds=[]`、`assetReview=original-design`。公式画像・漫画の切り抜き・既存ちびキャラ素材を同梱しない。原作外観の監査完了を表す値ではない。元資料側の未確認記録は変更しない。

64名はIDごとの明示行で、配色、12種の髪型、4種の顔、眉、眼鏡、6種の服装パターン、識別番号を選ぶ。スタイルの組合せは全件異なり、ハッシュや乱数で6パターンを割り振らない。番号・配色・隊服の線は自作判断で、通常部隊の公式衣装を採用したという意味ではない。三雲の眼鏡・暗い上着・07表示も自作の図形で描く。

各デザインに正面・背面・左・右を定義する。mainDirectionの0/90/180/270度は右/正面/左/背面へ丸める。左右では横顔と鼻、背面では顔を描かず髪と上着番号を表示する。バッグワーム装備またはstealth状態は暗緑の外套で示す。

41装備はIDごとのshapeKindとvariantを持つ。刀・槍、拳銃・散弾銃・突撃銃・狙撃銃・擲弾銃、射手弾、盾、壁、ワイヤー、専用optionを輪郭で区別する。改造品は別variant、長さ・幅・線数・補助色で区別する。レイガストshieldモードは幅広い盾輪郭へ切り替える。縮略形は装備分類を読むための自作図形であり、公式武器の精密形状を復元したものではない。

`drawPawn(ctx,x,y,options)` は足元を原点に描く。`PAWN_HEIGHT=26` を基準に、盤面側が0.6段の人体実寸へscaleを設定する。拡大識別badge・名前・コピー番号は盤面側が別に描く。optionsはpresetId/name/copy/teamColor/direction/main/sub/mainMode/subMode/stealth/moving/action/motionProgress/scale/reducedMotion。training/supplementedの別IDは同一人物の明示デザインへ解決する。

未解決IDは灰色の中立駒と?で示し、既知人物の姿へ割り当てない。

歩行の脚、射撃の反動、近接の振り、防御、被弾、回避、撃破に短い変形を使う。時刻や乱数を部品内で取得せず、呼び出し側から渡されたmotionProgressだけを使う。reducedMotionでは変形を停止し、射撃↗・近接╱・被弾!・防御◇・回避›・撃破×・歩行↔の記号を残す。これらは自作アニメーションであり、原作の動きの復元とは呼ばない。

描画部品は渡された公開状態だけを描く。不可視敵・レーダー・選択範囲を描く判断はBoard側の責務。部品から内部ユニットや原作素材を参照しない。

`tests/content/visual-assets.test.ts` は64/41のID・名称完全性、全件の自作根拠、スタイル組合せ、4方向、全装備・全動作・軽減設定のCanvas呼び出し、元台帳とM1.0/M1.1のSHA256を確認する。この自動試験は原作画像との人手比較や完成画面の外観審査を代用しない。

公開Gitには参考画像・公式画像入りの仕様HTML・個人用録画を含めない。CIと公開基準画像は`VITE_USE_OFFICIAL_ICONS=false`で作り、公式画像を含むローカル記録と分離する。外部画像URLの対応表は画像データの配布物ではない。
