# BattleSim

[![CI](https://github.com/ry32767/BattleSim/actions/workflows/ci.yml/badge.svg)](https://github.com/ry32767/BattleSim/actions/workflows/ci.yml)

公開リポジトリ: [ry32767/BattleSim](https://github.com/ry32767/BattleSim)。開発・変更の管理は [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

ブラウザで遊ぶ: [GitHub Pages版](https://ry32767.github.io/BattleSim/)。通常演習I〜III、6ターン戦闘、リプレイの保存・読み込みを利用できます。招待対戦は権威サーバーを起動した環境で利用します。

Pages版は `npm run build:pages` で生成し、`npm run test:pages` で `/BattleSim/` 配下の画面と両Workerを確認します。mainのCI合格後、GitHub Actionsがdistだけを自動公開します。

通常演習I・II・IIIの部隊編成、行動設定、同時戦闘、招待ルーム、結果とリプレイを備えるWeb実装です。設定150秒、実行15秒、全6ターン。陣営ごとに9・14・24体を扱います。

実行規則はR1.3、地形判定はG1/D1.1。64名・41装備・55効果の補完パックを使用し、既定のC2は住宅・モールのプロジェクト破壊目標を校正済みです。元のC1/B1も保存しています。確認済み能力と独自補完、スキル所有者の確認状況は分けて保存しています。原作内部式や全座標の完全復元を宣言するものではありません。検証の現在地は [実装状況](docs/implementation-status.md) を参照してください。

## 起動

Node.js 22.12以上を用意し、このディレクトリで実行します。

```powershell
npm ci
npm run dev
```

[http://127.0.0.1:5173](http://127.0.0.1:5173) を開きます。開発画面は5173、権威サーバーは3001で起動します。APIとWebSocketは開発画面からサーバーへ接続します。終了はターミナルでCtrl+C。

配布用ビルドを同じサーバーから表示する場合：

```powershell
npm run build
npm start
```

[http://127.0.0.1:3001](http://127.0.0.1:3001) を開きます。既定はこのPCからの接続のみです。LAN内の別PCと対戦する場合は、ビルド後に次のように起動し、参加者はホストPCのIPアドレスの3001番ポートを開きます。

```powershell
$env:HOST = '0.0.0.0'
npm start
```

サーバーのポートは環境変数 `PORT` で変更できます。LANから接続する場合はWindowsのファイアウォール設定も接続先に合わせてください。

## 遊び方

1. 段階、基礎四枠、ヘルプを選びます。練習用四名と、別時点の補完プリセットを区別します。
2. 練習を開始するか、招待ルームを作成・参加します。オンラインは各陣営1〜4人で、担当ユニットを分担できます。
3. 駒を選び、「行動」タブで経路・待機・追跡・護衛、「装備・向き」タブでMAIN/SUBを設定します。装備変更上限は段階I/II/IIIで2/3/5体です。
4. 15秒の同時戦闘を実行します。現在視認、射程、扇、3D射線が成立すると自動攻撃。戦闘と移動は同じAPを使います。
5. 6ターン末に生存数を比較します。差2/3/5体以上が勝利条件。出来事・原因・同時群は独立リプレイで確認できます。

PCの戦闘画面は左に盤面、右にレーダーと行動設定を配置します。部隊一覧・詳細・接触タグはポップアップで開きます。スマホでは「行動設定・レーダー」で下から操作パネルを開き、「最小化して盤面へ」で閉じます。編集状態は保持されます。レーダーは最小化・展開・拡大ができ、装備設定を開くと最小化されます。ページ全体はスクロールせず、長い設定・一覧はパネル内でスクロールします。

「装備・向きを反映」とM/Sハンドルのドラッグは、選択中のコマンドを更新します。ハンドルは放した時点で反映します。開始位置を選んでいる場合は、その装備・向きを持つ0.5秒のWAITを追加します。

| 操作 | 動作 |
|---|---|
| ホイール | 盤面の拡大・縮小 |
| 背景ドラッグ | カメラ移動 |
| M / Sハンドルをドラッグ | MAIN / SUBの向きを変更し、放すと反映 |
| 3DでShift＋背景ドラッグ | カメラ回転 |
| ↶ / ↷ / 北へ | 3Dを左右30°ずつ回転 / 回転をリセット |
| 駒を右クリック | 行動ポップアップ |
| 接触をダブルクリック | タグ・接触詳細ポップアップ |
| Enter | 表示中の移動経路を確定 |
| Esc | 編集取消 |
| Ctrl＋Z / Ctrl＋Shift＋Z | 元に戻す / やり直す |
| Home | 選択した駒へカメラを戻す |

M/Sハンドルにフォーカス中は矢印キーで5°、Shift＋矢印で15°ずつ向きを変更できます。平面表示とレーダーは北を上に固定します。タッチ操作では「部隊・接触一覧」や「その他の行動」「タグ・接触詳細を編集」から同じ設定を開けます。

レーダーは点と番号・タグを表示し、敵の高さや未視認の装備を表示しません。バッグワームはレーダーを隠し、光学視認では見えます。地形射撃、曲折弾、専用optionなどは固有行動の入力から設定します。

公開版の丸いバッジは自作駒を表示します。個人用のローカル環境で `.env.local` に `VITE_USE_OFFICIAL_ICONS=true` を設定した場合だけ、確認済みの公式URLを参照します（ビルド時に決まるため設定変更後は再起動・再ビルド）。戦闘中とリプレイでは味方・視認中の敵のMAIN/SUB扇を表示し、選択した駒を強調します。弾、斬撃、盾、トリガー発動を短い演出で示します。OSの動き軽減設定では静止した効果を表示します。[表示素材の対応と制約](docs/visual-assets.md)を参照してください。

リプレイの「前の行動tick」「次の行動tick」とシークは行動が起きた時点へ進みます。同時イベントは同じtickです。連続再生は元の15秒を保ちます。スマホのレーダー・出来事ログは下から開閉できます。注目する駒を選ぶと予定と実経路の相違や消費・中断へ移動できます。

通常移動・追跡・護衛でマスが重複し、経路に次の面がある場合は、重複面への着地を省略して進みます。各辺の移動時間・AP・登り制限は消費します。次の面がない・AP不足・足場消失時は停止します。これは利用者指定の独自拡張で、元のR1.3の競合後再試行とは区別して記録します。

リプレイのレーダーは盤面と同じフレーム・視点を表示し、再生・シーク・停止に追従します。オンラインの「前ターンのリプレイ」は完了済みの陣営記録を開きます。設定中に開いても行動設定の締切は進みます。

## データと検証

`npm run content:build` は台帳を変更せずC1/C2/M1.2を再生成します。[コンテンツの補完記録](docs/content-notes.md) と `data/runtime/manifest.json` に時点・根拠・可否を保存します。通常本人の全所有スキルが未確認の64候補は無効のまま、補完版を別IDで使用します。C2のプロジェクト校正と人手の原作比較は別の検証条件です。

```powershell
npm run typecheck
npm run lint
npm run test:engine
npm run test:server
npm run test:e2e
npm run test:visual
npm run build
```

配布ビルドのブラウザ検証では、ビルド後に次を実行します。Playwrightがポート3002のサーバーを起動・終了し、開発中の再読み込みが試験へ入るのを防ぎます。

```powershell
$env:VITE_USE_OFFICIAL_ICONS = 'false'
npm run build
$env:BATTLE_E2E_PRODUCTION = '1'
npm run test:e2e
npm run test:visual
$env:BATTLE_E2E_PRODUCTION = $null
```

実装は `packages/contracts`、`packages/content`、`packages/engine`、`packages/replay`、`apps/server`、`apps/web`。元の正典は [仕様資料のAGENTS.md](closed-battle-spec-v0.2/closed-battle-spec/AGENTS.md)、[R1.3](closed-battle-spec-v0.2/closed-battle-spec/docs/runtime-r1.md)、[G1/D1.1](closed-battle-spec-v0.2/closed-battle-spec/docs/map-spec.md) です。トリオン兵つくーるは次の製品フェーズです。

キャラを右クリックすると円形メニューが開きます（スマホは長押し）。MAIN / SUBから所持トリガーの扇形をクリックすると、その場で設定と盤面の扇へ反映します。開始選択では0.5秒の待機コマンドを追加し、行動コマンドの選択中はその装備を更新します。中央の戻る／閉じる、Esc、外側のクリックで戻れます。閉じても選択したトリガーは保持します。選択中のトリガーを再度押してもコマンドは増えません。

公式画像を含む参考資料・仕様HTML・個人用録画・一時出力・環境設定はGitに含めません。元の参考画像を必要とする厳密な資料検査は、画像を保持するローカル環境で行います。公開版のゲーム検証と画像比較は自作素材で実行できます。
