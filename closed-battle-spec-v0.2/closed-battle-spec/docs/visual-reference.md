v0.7の演算表示は[runtime-r1.md](runtime-r1.md)を優先。計画上限は32、演算は100ms×150tick、再生の「ステップ」はtickまたはイベント単位とする。下記の旧15コマンド/1秒ステップはR0時点の説明。MAIN/SUB・リプレイ独立・原因表示の画面契約は維持。地形ビューアは[map-spec.md](map-spec.md)の範囲だけを実装している。

更新日：2026-10-06。原作画面の観測に、戦闘の原因を追える表示とPC操作の独自設計を追加した。以下の操作・再生仕様は公式UIとして確認したものではない。

再確認したルールと最新モックの契約は[rule-review.md](rule-review.md)。建物は占有セル・屋上高さへ対応させ、リプレイは通常画面から開く独立したポップアップに変更した。公式サイトのデザイン参照範囲も同文書に記録する。

## 独自補完するデザイン値

基準キャンバスは1600×900。盤面領域は幅の76%、右パネル24%。上部にターンと残り設定時間、下部に設定コマンド列を配置。リプレイの時間軸・原因一覧は専用ポップアップへ置く。この比率・配置は公式寸法ではなく独自設計。

外枠・ナビは原作公式サイトを参考に濃紺・青/水色・角張った見出しを使い、盤面は低彩度、可視セルは白くする。味方は青、敵は橙で識別。この配色はシミュの公式色ではなく独自設計。モノクロ表示も切替可能。色だけで区別せず、陣営マーカーと名前を併用する。

駒は正面・左右・背面を最低限用意する。歩行、射撃、近接、被弾、撃破の短い動きは自作し、原作アニメーションを復元できたと表示しない。現役の装備とバッグワーム着用状態を駒へ反映する。

地面の六角形座標を描画用の斜め投影へ変換する。論理座標は描画座標から独立。建物の裏にいる味方／可視敵は輪郭表示や屋根の透過で選択可能にする。不可視敵は透過表示でも露出させない。

## 操作状態

未選択／ユニット選択／移動編集／範囲方向編集／装備切替／追跡指定／待機設定／実行中／結果を区別。範囲をドラッグして向きを変えられる。MAINとSUBは別々に編集する。攻撃方向、視界、経路、選択枠を混同しない。

複数操作者では自分の担当駒を強調し、味方の予定を薄い線で表示。他人の担当駒を選ぶと閲覧のみになる。右パネルへ担当者を表示。

## 見た目の受け入れ条件

- V1にある盤面／右パネルの構成、V2にある駒／2つの扇形／経路を同じ自作画面内で確認できる。
- 近接と狙撃で扇形の長さが異なり、シールドの向きが分かる。
- 3段階の最大24体／陣営でも駒を選択でき、名前は重なりを抑える。
- 1366×768と1920×1080で右パネルのボタンが画面外に消えない。拡大縮小、盤面移動で密集した駒を選べる。
- 各操作状態の自作スクリーンショットを保存。人間がV1/V2との構成・形状の対応を確認する。
- 漫画で未確認の配色・比率・アニメーションは独自補完としてdocsに残す。

キャラクター選択画面、ルーム画面、タイムラインの詳細は公開画像で十分に確認できていないため、盤面の雰囲気に合わせて独自設計する。

## 戦闘を理解するための画面構成

原作風の斜め俯瞰2Dを主画面とし、正確な位置を確認する平面表示へ切替可能にする。双方は同じ論理座標・選択・時刻・カメラ注目位置を使う。射線・光学視界の内部判定は[マップ仕様](map-spec.md)のG1共通3D形状から行い、その同じ形状を主画面へ投影する。カメラや表示モードから遮蔽を判定しない。写実的な3Dの別戦闘を作らない。建物・高低差は保持し、平面表示でも高さ数字と屋上マークを表示する。

| 領域 | 内容・目的 |
|---|---|
| 上部 | 段階、ターン、設定/実行/振り返り、残り設定時間、生存数。締切と見ているターンを常に区別 |
| 主盤面 | 六角、市街地、駒、陣営・個体番号、選択枠、MAIN/SUB。何がどこで動いたかを示す |
| 右上 | レーダー。盤面の可視敵と匿名探知点を別形状で表示 |
| 右中央 | 検索・担当/キャラ/複製番号で絞るユニット一覧。選択中のAP・待ち・装備・状態・操作者 |
| 右下 | 通常画面は選択駒・コマンドの装備/状態。リプレイのポップアップでは選択時刻の出来事・理由を連動表示 |
| 下部 | 通常画面は設定コマンド列。実行時は経過。再生操作・時間軸は独立ポップアップ内 |

HP等の表示値は採用RuleSetに合わせる。R1が未決定の段階でHP制を見た目から確定させない。同じキャラの複製は「三雲-1」等の個体番号を常に表示可能にし、名前だけで識別しない。

### 重なりと情報量

通常は選択駒の範囲・予定だけを強調。味方予定は任意表示、敵の扇形はその時点で開示可能な装備・向きに限る。全駒の扇形・名前・弾道を常時重ねない。射程、警戒範囲、射線、視界は独立した表示切替と凡例を持つ。射程内でも射線遮断なら遮断点を表示する。

建物は選択対象付近だけ透過し、可視駒の輪郭を示す。密集セルのクリックは候補一覧を開く。ユニット一覧から選んでも盤面を中央へ移動できる。レーダーの点をクリックすると座標へ移動し、匿名点から正体を表示しない。

色と形・線種・文字を併用する。MAINは実線＋M、SUBは破線＋S。予定経路は破線、実経路は実線。被弾・防御・回避・不発を異なる記号と短文で表示。軽減モードでは画面揺れ・点滅・自動カメラ移動を止めても、出来事と理由を失わない。

## 行動設定の操作契約

操作は「選択 → 経路 → コマンド位置ごとの装備/向き → 確認」。自動攻撃の開始条件はRuleSetに従い、クリックした敵への攻撃確約として見せない。

| 操作 | 仕様 |
|---|---|
| 駒選択 | 左クリックまたは一覧。選択だけでは既存プランを変更しない |
| 経路編集 | 移動ボタンで編集に入り目的セルをクリック、Shiftクリックで経由点追加。経路・高さ・基礎APをプレビューし、確定ボタン/Enterで反映 |
| 装備・方向 | 対象コマンドを選びMAIN/SUBを別編集。R0の6方向限定は独自補完、R1へ確定採用しない。ドラッグと角度ボタンを用意し、角度刻みは操作検証で決める |
| 追跡 | 追跡ボタンから探知可能対象を選ぶ。見失った場合の最後の既知位置と待機動作を説明 |
| 待機・順序 | コマンド列でWAIT挿入、削除、ドラッグまたは上下ボタンで並替え。R1では最大32コマンドを表示 |
| カメラ | ホイールでカーソル地点を中心に拡縮、背景ドラッグ/中ボタンドラッグで移動。Homeまたは全体表示ボタンで戻す |
| 取消・復元 | Escで未確定編集を取消。Ctrl+Z/Ctrl+Shift+Zで確定編集を戻す/やり直す。自分の現在ターンの変更のみ対象 |
| 担当移動 | 一覧の次/前ボタンとTab/Shift+Tabで自分の駒を巡回。入力欄やダイアログ内のTabは通常のフォーカス移動 |
| 複数設定 | 自分の担当だけを複数選択し、待機・装備/向きの一括変更。確認前に対象数と不適合理由を表示。経路の一括貼付は初期対象外 |

右クリックは取消の補助とし、右クリック・ドラッグ・ショートカットだけでしかできない必須操作を作らない。ボタンは日本語ラベル/説明を持ち、クリック領域は最低32×32px。文字入力中は盤面ショートカットを発火させない。

APプレビューは「移動等の予定消費」と「戦闘による追加消費」を分ける。未知の相手行動・命中・防御消費は確定予測しない。「戦闘がなければ到達」の終点と、AP不足/待ちにより中断する可能性を示す。通行不可、上昇制限、コマンド上限超過は確定前に理由と修正箇所を表示する。味方との同時競合は予測できる範囲だけ警告する。

編集中/送信中/サーバー受理済み/拒否を区別し、受理済みだけを保存完了と表示する。相手や別担当は閲覧のみ。担当変更後は旧担当の編集とUndoを拒否し、未確定編集は破棄、受理済みプランを新担当へ渡す。最終提出は受理済み一覧を確認できる。未準備駒・無行動駒・エラー数を示し、締切時には主仕様のWAIT等を適用する。

## 同時実行の見せ方

実行15秒の通常表示を維持し、演算の100ms tick間を移動アニメーションで補間する。補間は判定を作らず、弾の描画位置から命中や遮蔽を再計算しない。発射、遮断、防御、被害、撃破を演算イベントから描画する。弾速・斬撃・爆発の見た目は独自演出として定義する。

同時攻撃は同一ステップのグループとして表示する。相撃ちは双方の攻撃→被害→同時撃破を一組で示す。先行スキルが発動した場合は先行群と取消を区別する。見やすさのため演出を時間差で表示しても、ログに同時刻と明示し、順番に行動したと誤認させない。

全体表示を初期値とし、駒追従・イベント追従は任意。別地点の戦闘は盤面端マーカー・レーダー・イベント一覧から見に行ける。イベント追従中でも手動パンで解除できる。オンライン中のサーバー進行・150秒の設定締切は再生操作で停止しない。

## 振り返りと試合後リプレイ

各ターン終了後は、自陣営に開示済みの記録を次の設定中に振り返れる。設定タイマーは進み、振り返り画面に残り時間と「現在の設定へ戻る」を固定表示する。過去ターンのプランは編集不可。試合後は参加者に全体リプレイを解禁する。

振り返りは専用ポップアップで開く。通常画面の選択・未確定編集・経路・カメラを保持し、再生側は別の選択・カメラ・時刻を持つ。背景は操作不可。閉じる/Escで設定へ戻り、起点へフォーカスを戻す。詳細は[再監査](rule-review.md)の契約に従う。

- 再生/停止、0.25/0.5/1/2倍、前/次ステップ、前/次イベント、時間軸のクリック移動を提供する。設定中の振り返りではライブ実行を操作しない。
- イベント一覧を駒・陣営・種類（攻撃/防御/撃破/中断/探知等）で絞れる。行クリックで時刻へジャンプし、関係駒・射線・遮蔽点を強調する。
- 試合後は「全体」「各陣営が当時知っていた情報」を切替。同じ視点の当時の開示履歴を再現し、後で判明した正体を先の時刻に出さない。
- 予定/実経路の比較で、最初の食い違いとAP消費・待ち・移動競合・撃破の理由へ移動できる。結果から撃破場面へ戻れる。
- 逆再生は保存状態/イベントから過去状態を復元する。新しい乱数抽選・戦闘の再実行で結果を作らない。読込不備・版不一致は説明して停止する。

表示例（独自の説明例であり原作戦闘記録ではない）：「T2 7秒：三雲-1は予定の屋上へ未到達。6秒の防御でAPを1消費し、次の移動に必要なAPが不足」。そのイベントを選ぶと防御と中断位置を示す。不可視攻撃の原因は対戦中「攻撃元不明」とし、非公開の名前・射線開始点・相手能力を出さない。

## 原因を説明するイベント契約

Replay.eventsは判定済み事実を保存する。描画と説明は同じ記録を使い、ブラウザが独自の命中計算や理由推定をしない。

| 情報 | 必須の内容 |
|---|---|
| 識別・時刻 | eventId、turn、step、処理phase、同時groupId、同一群内の安定した表示順 |
| 関係 | 行為者/対象ID、前提イベント/原因ID、元planのrevisionとcommandIndex |
| 空間 | 始点・終点・高さ・判定射線・遮蔽点。イベント種類に応じて必要なもの |
| 結果 | 攻撃/命中/防御/回避/不発/被害/撃破/中断/探知変化、状態の前後差分 |
| 原因 | 射程外、範囲外、遮蔽、未探知、AP不足、待ち、競合、スキル等のreasonCodeと適用効果ID |
| 消費 | 移動・攻撃・防御・維持ごとのAP前後、待ち前後、採用ルールに応じた被害計算の内訳 |
| 再生 | rule/content/mapVersion、チェックポイントと状態差分。任意時刻を復元できる情報 |

完全記録はサーバー内のみ。対戦用には観測可能なイベントへ変換し、原因ID・同時群・差分・射線にも敵情報が漏れないようにする。IDは公開用へ付替え、隠れたイベント数/順序を推測できる全体連番や欠番を送らない。必要な理由は「不明」とし、虚偽の理由を表示しない。チェックポイントも陣営別に秘匿する。試合後の当時視点を作れるよう各陣営への開示内容・時刻を記録する。
