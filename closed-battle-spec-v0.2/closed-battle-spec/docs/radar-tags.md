# レーダー・探知・タグ仕様 v0.6

2026-10-06。ユーザー指定の表示・操作を定義する。今回も仕様と表示確認モックのみ。自動採番・不確実性の輪・区画記号は本アプリの補助設計で、原作の確定機能として扱わない。原作でのタグ操作はユーザーからの観測として採録し、閉鎖環境シミュへの実装範囲は本仕様で決める。

## レーダーと盤面の対応

レーダーは読める面積を取り、北を上にした平面表示で地形の概形、味方、探知対象を示す。盤面と同じ区画記号・向きを使う。斜め俯瞰への切替は高さ表現のみを変え、左右の対応を反転させない。将来カメラ回転を導入する場合は、北表示とレーダー上の表示範囲を追加する。

未視認の敵は盤面へ疑問符、レーダーへ点を表示し、同じ番号/タグで対応させる。レーダー内にはキャラ画像・顔・キャラ名を出さず、視認後も点と番号/タグを維持する。盤面では探知報告の平面位置に置き、屋上・地面などの面、高さ、向き、装備を推測で描かない。位置に幅がある報告は目安の輪を添える。輪の大きさは表示確認用の仮値。原作レーダーの位置精度・更新間隔・高さ情報の有無は調査継続とし、勝手に誤差を戦闘計算へ追加しない。

レーダーのマーカー、盤面の疑問符、対象一覧は相互に選択を同期し、選択対象の区画・観測状態を表示する。探知のみの対象は情報選択として扱い、クリックで視界外の敵への攻撃を確約しない。キーボード操作は対象一覧とタグ入力から行える。

## 観測状態

| 状態 | レーダー・盤面 | 名前・アイコン |
|---|---|---|
| 探知・未視認 | 盤面は疑問符、レーダーは点。番号/タグと報告位置の目安 | 未識別。名前・顔・装備を露出しない |
| 視認 | 盤面は名前とキャラアイコン、観測された面・位置。レーダーは点と番号/タグ | 視認で識別できた名前を表示。番号と手動タグは保持 |
| 視界外・探知継続 | 盤面は疑問符に戻す。レーダーは点。最新の探知報告位置 | 過去に識別した名前は「既知」として記録に残す。現在の姿・向き・装備と混同しない |
| 失探 | 最終探知位置を淡色・破線にして明示 | 最終探知時刻と「現在位置不明」を表示。真の位置で自動更新しない |
| 再探知 | 新しい探知報告に従う | 同一対象と裏付けられる場合のみ番号を引継ぐ。判断できなければ新規番号とし、推定の関連付けを確定識別にしない |

名前とキャラアイコンだけでは複製ユニットを区別できないため、ユニット枝番または接触番号を併記する。視認しても複製の個体まで確定できない場合は、キャラ名の識別と個体の識別を別の状態として保持する。

## タグと自動番号

- 接触番号は自陣営が初めて取得した探知報告へE01、E02…を付与。視認前には相手の内部IDや名前を使わない。陣営内で一意にし、失探・撃破後の番号も同一試合中に再利用しない。
- 自動番号は既定ONの補助機能。OFFでも手動タグを使える。ON/OFFやタグ解除で内部の接触番号を振り直さない。
- タグは対象選択→入力→保存またはEnter。12文字までの短いラベルとし、空欄/タグ解除で自動番号表示へ戻る。自動番号OFFの場合は「未識別」表示へ戻る。
- 手動タグを優先表示し、元の接触番号は対象の詳細に残す。同じ文字列のタグを付けても別接触を自動統合しない。
- 視認時にも手動タグを保持し、キャラ名と併記する。タグはメモであり、入力した名前が識別済み情報へ昇格するわけではない。
- 専用オペ役を必須にせず、自陣営の操作担当者全員が使える。陣営内で共有し、同時編集はサーバーが順序を付ける。相手陣営へ送信しない。

## 情報とリプレイの契約

光学視認の遮蔽は[マップ仕様](map-spec.md)のG1共通3D形状からサーバー/練習エンジンが判定する。面の可視マスク、敵の身体サンプルの視認、レーダー報告は別の結果。クライアントのカメラ位置や地形透過は観測を変更しない。

画面は陣営別Observationを受け取る。contactId、報告平面位置、位置精度、観測種別、観測時刻、識別済み情報、手動タグ、接触番号を持つ。真の敵座標・高さ・装備を未視認描画へ流用しない。contactIdは公開用の接触IDであり、敵ユニットの内部IDではない。

探知・視認・識別・失探・タグ変更を時刻付きイベントとして記録する。リプレイは再生時刻までの観測とタグだけを復元する。後で判明した名前や現在のタグを過去時刻へ遡って表示しない。試合後の全体視点は別の情報範囲として扱い、当時視点の判定を上書きしない。

モックの「視認する」「探知解除」は表示例を切り替える確認用操作。本番でユーザーが探知や識別を成立させるボタンではない。位置・輪・時刻・識別例は説明用データで、戦闘エンジンによる結果ではない。

## 公式ちびキャラ

公式公開元[S17](https://worldtrigger.info/article/quiz.php)のTwitter用・個人用・再配布/用途制限の記載は資料として保持する。2026-10-06、ユーザーから「非公開・個人利用のため採用する」と指示を受けた。これはユーザーの利用方針と作業指示であり、権利者によるシミュ用途の許諾が確認できたという記録ではない。

今回の個人用ローカルモックでは公式配布URLを直接参照して盤面アイコンに使用する。非公開、配布・公開用パッケージやゲームマスターへの素材同梱は行わない。公式画像のダウンロード・加工・再配布は今回の作業に含めない。三雲01、隠岐45、樫尾53、香取63、諏訪67、出水12の対応と描画をブラウザで確認した。ダミーの味方ユニットは仮アイコンを保持する。

公式アイコンを表示する最新モックはローカルの専用画面。会話内の旧モックは仮アイコンの過去版として残す。画像の取得には公式配布元へのネットワークアクセスが必要。

## 受け入れ条件

- 同じ探知報告が盤面とレーダーで同じ区画・番号/タグとして読める。
- レーダー、盤面、対象一覧の選択が同期し、キーボードからタグの保存・解除ができる。
- 自動番号をOFF→ONにしても、同じ接触番号と手動タグを保持する。
- 視認前はキャラ名・顔が表示されず、盤面の視認後は名前・アイコンと番号/タグを併記する。レーダーには視認後もキャラ画像・キャラ名を表示しない。
- 視認解除後は疑問符へ戻し、失探後は最終探知と現在位置を混同しない。
- リプレイを過去へ戻すと、未来の識別情報・タグ変更が消える。
- 位置精度・識別能力・再探知対応は補完マスターで定義し、原作確認済みの規則と区別する。
